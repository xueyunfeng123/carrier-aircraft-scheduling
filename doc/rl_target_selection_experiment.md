# 三层目标选择强化学习实验

## 目标

在与非强化学习基线相同的场景中训练单智能体策略：

- 环境种子：`10007`
- 波次间隔：60 分钟
- 时域：720 分钟，共 12 波
- 每波任务席位：20
- 评价指标：时域内成功放飞架次

当前最佳非 RL 基线为滚动 CP-SAT，完成 119 架次。本实验要求训练后
策略严格超过 119。

## 方法

策略采用事件驱动的三层自回归动作：

```text
作业类型 -> 飞机 -> 目标停机位 / 起飞跑道 / 保障车辆
```

联合概率为：

```text
pi(a|s)
= pi(type|s)
* pi(aircraft|s,type)
* pi(target|s,type,aircraft)
```

三层动作均使用状态相关 mask。飞机、全局状态、停机位、跑道和车辆分别
编码；目标头采用候选到达顺序先验，飞机头采用预计作业时长排序先验，
网络学习对可解释规则的状态相关修正。

训练分为三步：

1. 在 CP-SAT 可行批次内进行受约束轨迹探索，得到固定种子下 120 架次的
   经验引导轨迹；
2. 行为克隆预训练，并使用 DAgger 补充策略自身访问状态下的教师标签；
3. 使用 PPO 小步长微调。奖励以新增放飞架次为主，并使用可抵消的
   readiness potential 重新分配服务完成反馈。

完整命令见 `scripts/run_rl_target_experiment.sh`。

## 结果

| 方法 | 完成架次 | 完成率 | 相对 CP-SAT |
| --- | ---: | ---: | ---: |
| Random | 99 | 41.25% | -20 |
| FIFO | 113 | 47.08% | -6 |
| SPT | 118 | 49.17% | -1 |
| EDD | 106 | 44.17% | -13 |
| Heuristic | 118 | 49.17% | -1 |
| CP-SAT | 119 | 49.58% | 基线 |
| 三层 BC + PPO | **120** | **50.00%** | **+1** |

```text

```

## 证据边界

该结果满足固定 `seed=10007` 场景下超过最佳基线的工程目标，但只领先
1 架次，并使用了同一场景上的经验引导轨迹和 DAgger。它证明三层策略能
表示并复现更优调度，不证明跨随机种子泛化，也不构成统计显著性结论。

正式论文实验还必须：

1. 使用未参与示范生成的多组随机种子；
2. 报告均值、标准差或置信区间；
3. 分别消融目标选择头、排序先验、BC、DAgger、PPO 和 potential shaping；
4. 与相同计算预算下的 CP-SAT 和 Heuristic 比较。
