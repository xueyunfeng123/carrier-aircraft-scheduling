# 海天杯甲板空间环境结构版

## 口径

本环境复用 `海天杯-技术资料0929更新.pdf` 的空间结构和作业规则，
但保留本项目的 45 架共享甲板机队、每波动态选择 20 架和多波次闭环。
该资料描述的是虚拟航空枢纽，因此本实现属于结构化场景假设，不代表
真实航母甲板几何。

## 拓扑

- 45 个保障停机位分为四区：西北 10、东北 13、西南 12、东南 10。
- 1 条西侧着陆跑道。
- 3 条东侧起飞跑道。
- 北、中、南三排通道各含 5 个节点；三个位置设置纵向连接。
- 停机位以短支路连接所在区域附近的北侧或南侧通道。
- 当前边权统一为 1 分钟，是待校准结构参数。
- 飞机与车辆均在 `(节点, 时间片)` 状态空间中使用 Cooperative A*。
- 节点同刻互斥，同一条边的同向重叠和对向会车均互斥；规划器可插入
  等待动作避让冲突。
- 该离散时空预约相当于拓扑图上的时空 Tube。它借鉴 Yoon 2023 的
  逐节点容量，以及 Deng 2025、Guo 2026 的候选路径和延迟消冲突思想，
  但不是连续二维凸包碰撞仿真。

## 移动保障车辆

高层动作扩展为：

| 动作 | 含义 |
| --- | --- |
| `R` | 回收 |
| `F` | 加油 |
| `M` | 装弹 |
| `L` | 放飞 |
| `I` | 检修 |

加油车、检修车、装弹车和牵引车具有独立的当前位置与忙闲状态。保障车
从当前位置沿甲板图到达目标飞机所在停机位，移动时间计入作业完成时间。
车辆完成作业后停留在该位置，下一次调度从新位置出发。

放飞和回收采用两段牵引流程：

1. 空闲牵引车从当前位置空驶到飞机位置；
2. 牵引车与飞机组成一个移动实体，沿无冲突路径到达目标停机位或跑道。

牵引车空驶、飞机牵引和所有保障车辆移动共享同一节点/边预约表。

停机位采用分层占用：

- 飞机容量为 1；
- 保障车辆不占用飞机容量；
- 不同类型且无互斥关系的保障作业可以在同一架飞机上并行；
- 每辆保障车同一时间只能服务一架飞机。

当前没有额外添加停机位车辆数量上限，因为资料允许无互斥关系的作业
并行，也没有给出该上限。

## 动作目标与作业状态

- 回收动作显式选择目标停机位。
- 放飞动作显式选择三条起飞跑道之一。
- 加油、检修和装弹动作显式选择一辆可达的空闲保障车。
- 确定性基线按无冲突最早到达选择目标；Random 对合法目标均匀采样。
- 暂不允许飞机在保障过程中多次更换停机位。
- 燃油采用 `[0, 1]` 连续状态；默认出动后余油为 `0.2`，加油速率为
  `0.05/分钟`，工时由缺油量除以速率得到。
- 人员调度默认关闭；当前约束只保留车辆、升降机、停机位、跑道和路径。

## 海天杯干涉映射

- 起飞跑道 29、30 分别关联一个按45机位布局映射的东侧邻接机位；
  跑道31不设置停机位阻塞，避免满甲板初态死锁。
- 跑道29与30互相干涉，释放后保留0.5分钟间隔。
- 每个停机区保留一组边缘机位进场干涉，释放后保留2分钟间隔。
- 原PDF的28机位编号不能逐项复制到45机位图，上述规则属于保持物理关系
  的稀疏映射，而不是原干涉表的数值复刻。

## RL 与求解器

- 新增检修动作后，高层动作数由 4 增至 5。
- 连续燃油和稳定飞机标识加入后，单机观测增至 23 维。
- 全局观测由 19 维增至 20 维。
- 目标/车辆候选另行编码，observation schema 升级为 9，旧 checkpoint
  必须重新训练。
- Heuristic、FIFO、SPT、EDD、Random 和 CP-SAT 均已适配。
- 当前 RL 网络学习“作业类型 + 飞机 + 停机位/跑道/车辆”三层动作。

## 验证

- 全量单元测试：66 项通过。
- 统一基准：`seed=10007`、60 分钟波次、12 波、单次运行。

| Solver | 完成架次 | 完成率 |
| --- | ---: | ---: |
| Random | 99 | 0.4125 |
| FIFO | 113 | 0.4708 |
| SPT | 118 | 0.4917 |
| EDD | 106 | 0.4417 |
| Heuristic | 118 | 0.4917 |
| CP-SAT | 119 | 0.4958 |
| RL（BC+PPO） | 120 | 0.5000 |

结果保存于 `outputs/rl_target_selection_60min_seed10007.csv`。六种非 RL
基线均可完成事件闭环；三层 BC+PPO 在该固定种子下完成 120 架次，比
CP-SAT 多 1 架次。RL 使用同场景经验引导轨迹，该结果仅证明策略表示和
训练链路可达到目标，正式优劣仍需未见多种子统计。
