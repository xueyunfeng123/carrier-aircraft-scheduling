# 海天杯甲板空间环境结构版

## 口径

本环境复用 `海天杯-技术资料0929更新.pdf` 的空间结构和作业规则，
但保留本项目的 45 架共享甲板机队、每波动态选择 20 架和多波次闭环。
该资料描述的是虚拟航空枢纽，因此本实现属于结构化场景假设，不代表
真实航母甲板几何。

## 拓扑

- 45 个保障停机位分为四区：西北 10、东北 13、西南 12、东南 10。
- 1 条西侧着陆跑道。
- 3 条东侧起飞跑道。
- 北、中、南三排通道各含 5 个节点；三个位置设置纵向连接。
- 停机位以短支路连接所在区域附近的北侧或南侧通道。
- 当前边权统一为 1 分钟，是待校准结构参数。
- 飞机移动暂沿图最短路并采用整路原子预留，时空 Tube 预留留待下一步。

## 移动保障车辆

高层动作扩展为：

| 动作 | 含义 |
| --- | --- |
| `R` | 回收 |
| `F` | 加油 |
| `M` | 装弹 |
| `L` | 放飞 |
| `I` | 检修 |

加油车、检修车和装弹车具有独立的当前位置与忙闲状态。车辆从当前位置
沿甲板图到达目标飞机所在停机位，移动距离计入作业完成时间。车辆完成
作业后停留在该停机位，下一次调度从新位置出发。

停机位采用分层占用：

- 飞机容量为 1；
- 保障车辆不占用飞机容量；
- 不同类型且无互斥关系的保障作业可以在同一架飞机上并行；
- 每辆保障车同一时间只能服务一架飞机。

当前没有额外添加停机位车辆数量上限，因为资料允许无互斥关系的作业
并行，也没有给出该上限。

## RL 与求解器

- 新增检修动作后，高层动作数由 4 增至 5。
- 单机观测由 18 维增至 21 维。
- 全局观测由 19 维增至 20 维。
- observation schema 升级为 4，旧 checkpoint 必须重新训练。
- Heuristic、FIFO、SPT、EDD、Random、SampledRandom 和 CP-SAT 均已适配。

## 验证

- 全量单元测试：33 项通过。
- 统一基准：`seed=10007`、60 分钟波次、12 波、单次运行。

| Solver | 完成架次 | 完成率 |
| --- | ---: | ---: |
| Random | 148 | 0.6167 |
| FIFO | 139 | 0.5792 |
| SPT | 146 | 0.6083 |
| EDD | 141 | 0.5875 |
| Heuristic | 147 | 0.6125 |
| SampledRandom | 148 | 0.6167 |
| CP-SAT | 146 | 0.6083 |

结果保存于 `outputs/haitian_mobile_services_60min_seed10007.csv`。该结果
证明七种非 RL 基线均可完成事件闭环。Heuristic、SPT 和 CP-SAT 已将空闲
保障车辆到目标停机位的最短移动时间纳入优先级；Heuristic 与 CP-SAT
采用回收优先，避免待回收飞机长期滞空。单个固定种子的数值不能作为算法
优劣结论，三跑道干涉加入后仍需重新评估。
