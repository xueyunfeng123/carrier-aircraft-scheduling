# RL 泛化与先验依赖迭代

## 研究问题

固定 `seed=10007` 的三层 BC+DAgger+PPO 策略完成 120 架次，超过正式
CP-SAT 基线的 119 架次。但原训练过程使用了同一场景的 `elite_cp`
轨迹和 DAgger 标签，且飞机 logits 固定叠加权重为 4.0 的 SPT 排序项。
因此需要回答：

1. 策略能否泛化到未参与训练的随机种子；
2. 性能来自神经网络还是固定排序规则；
3. PPO 是否在教师策略基础上产生了可验证改进。

## 实验协议修正

训练脚本现支持显式 `--train-seeds` 与 `--validation-seeds`，默认拒绝
两个集合重叠。DAgger 只从训练种子采集状态，不再使用验证种子。最佳
checkpoint 按验证集平均完成架次、最差完成架次和缺额依次选择。

基准脚本可通过 `--detail-output` 保存逐求解器、逐种子的配对数据；
RL 评估脚本可通过 `--output` 保存逐种子结果。

## 未见种子结果

诊断种子为 `20001-20005`，不参与训练或模型选择。

| 方法 | 平均完成架次 | 标准差 |
| --- | ---: | ---: |
| Random | 98.4 | 0.89 |
| FIFO | 113.4 | 0.55 |
| SPT | 118.2 | 0.84 |
| EDD | 107.4 | 1.14 |
| Heuristic | 117.8 | 0.84 |
| CP-SAT | 119.6 | 0.55 |
| Elite CP 教师 | 120.0 | 0.71 |
| 原固定先验 RL | 120.0 | 0.71 |

原 RL 在未见种子上没有崩溃，并比正式 CP-SAT 基线平均多 0.4 架次。
但其均值和标准差与 `elite_cp` 教师相同，尚无证据证明 RL 超过教师。

## 先验消融

在同一网络权重和同一批诊断种子上，仅改变推理时的先验强度：

| 飞机排序先验 | 目标排序先验 | 平均完成架次 |
| ---: | ---: | ---: |
| 4 | 4 | 120.0 |
| 4 | 0 | 120.0 |
| 3 | 0 | 119.4 |
| 2 | 0 | 119.2 |
| 1 | 0 | 117.2 |
| 0 | 0 | 113.2 |

目标头在关闭固定目标先验后保持性能，说明目标选择主要由网络完成。飞机
选择在关闭 SPT 排序项后下降 6.8 架次，说明原模型的主要性能仍依赖固定
飞机排序规则。

## 学习式排序门控

新增按全局状态和作业类型输出权重的飞机排序门控。门控可以从固定先验
平滑初始化，也可以从零初始化后通过示范数据学习。

零初始化门控使用 8 个训练种子的 `elite_cp` 示范进行 100 epoch BC：

- 训练样本：3513；
- 联合动作准确率：73.53%；
- 高层动作准确率：85.88%；
- 飞机动作准确率：87.65%；
- 目标动作准确率：100%；
- 独立验证种子 `31001-31003`：平均 119.67；
- 诊断种子 `20001-20005`：平均 119.8；
- 对同一 checkpoint 关闭学习式门控：平均 111.4。

这说明排序偏好可以由数据学习，而不必在推理时写死为 4.0，但当前学习式
门控仍略低于固定先验版本。

在此 checkpoint 上继续进行 4 次多种子 PPO 更新，基础网络学习率为
`3e-6`，门控学习率为 `1e-4`。最佳模型来自 update 3：

- 验证种子 `31001-31003`：平均 120.33，最差 120；
- 诊断种子 `20001-20005`：平均 119.8；
- 诊断集关闭学习式门控：平均 112.0。

## 冻结测试

模型和超参数冻结后，在未参与训练、验证或前期诊断的
`seed=40001-40020` 上测试：

| 方法 | 平均完成架次 | 标准差 | 95% 正态近似区间 |
| --- | ---: | ---: | ---: |
| CP-SAT | 119.50 | 0.607 | [119.234, 119.766] |
| Elite CP 教师 | 119.80 | 0.616 | [119.530, 120.070] |
| 固定先验 RL | 119.75 | 0.716 | [119.436, 120.064] |
| 学习门控 BC+PPO | **120.20** | **0.696** | **[119.895, 120.505]** |

学习门控 BC+PPO 相对 CP-SAT 平均增加 0.70 架次，逐种子为 14 胜、
5 平、1 负，双侧配对符号检验 `p=0.00098`。相对固定先验 RL 平均增加
0.45 架次，为 9 胜、9 平、2 负，符号检验 `p=0.0654`。因此前者已有
显著证据，后者目前只能视为改善趋势。

相对 `elite_cp` 教师平均增加 0.40 架次，为 9 胜、8 平、3 负，符号
检验 `p=0.1460`。均值更高但没有显著证据，不能声称已经稳定超越教师。

## 当前结论

当前方法应描述为“经验引导的层次强化学习”，而不是纯 PPO：

1. BC 和 DAgger 用教师数据初始化策略；
2. PPO 在教师策略附近优化；
3. 新版本将固定 SPT 权重替换为按状态和作业类型学习的门控。

可作为论文贡献的是事件驱动三层自回归动作、完整合法性 masking、甲板
时空冲突下的目标选择，以及可学习的经验先验门控。20 个冻结测试种子
支持其优于当前 CP-SAT 基线，但尚不足以证明学习门控显著优于固定先验
RL。

正式论文还应增加不同波次间隔、资源规模与扰动强度的分布外测试，并完成
BC、DAgger、PPO、固定先验和学习式门控的完整消融。
